Ldash

Everything you need

A personal ops dashboard in the laden.no language: apps, monitor, calendar, sticky notes and subscriptions — Ctrl+` and you are in.

Type
Desktop-app
Stack
JavaScript, Python, C#
Role
Produktutvikling

Surface

Challenge

We wanted a light, hack-like dashboard that opens on a shortcut: your apps, host monitoring, calendar, sticky notes and subscription overview — without the heavy enterprise feel.

Move

Ldash is built as an Electron shell with a React UI in the laden.no palette (void, hack-green, cyan). Widgets can be dragged in edit mode, size classes adapt and Control Panel gathers the settings. The prototype is packaged for three OSes so you can test it locally.

Stack

Electron + Vite + React + TypeScript + Zustand. System metrics via a native bridge. The same visual language as Lab'z — Orbitron titles, grid, scanlines — made for daily use, not show.

Download v1.0

Mac · Windows · Linux · Android

Unsigned test builds. macOS may ask about Gatekeeper — right-click and open, or allow it under Privacy. Windows SmartScreen may warn; choose ‘More info’ and run it anyway. Linux: make the AppImage executable (chmod +x).
