Ldash

Everything you need

Personlig ops-dashboard i laden.no-språket: programmer, monitor, kalender, sticky notes, abonnementer — Ctrl+` og du er inne.

Type
Desktop-app
Stack
JavaScript, Python, C#
Rolle
Produktutvikling

Flate

Utfordring

Vi ville ha et lett, hack-aktig dashboard som åpnes på snarvei: egne programmer, host-monitorering, kalender, sticky notes og abonnementsoversikt — uten tung enterprise-følelse.

Grep

Ldash er skrevet i JavaScript. Samme HTML-side er dashbordet på alle systemer, i laden.no-paletten (void, hack-green, cyan). Widgets kan dras i redigering, og Control samler innstillingene. Python gjør skrivebordsjobben bak siden. Windows og Mac leverer den i et C#-vindu, Android er Kotlin, og iPhone-versjonen er Swift.

Stack

Skjermen er JavaScript, HTML og CSS. Titler bruker Orbitron. Python er skrivebordsverten. Linux åpner et GTK 4-vindu med WebKit. Windows er et C#-vindu på WebView2, med Python i installasjonen. Mac er et C#-vindu på systemets WebKit. Android er Kotlin og viser samme JavaScript i WebView.
